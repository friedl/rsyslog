## Folie 3: Kernprodukt – rsyslog (Open Source)
*   **Was es ist:** Ein extrem schneller, modularer und sicherer Log-Processing-Dienst.
*   **Hauptmerkmale:**
    *   Verarbeitet über 1 Million Nachrichten pro Sekunde.
    *   Unterstützt modernste Protokolle wie **RELP** (Reliable Event Logging Protocol) für verlustfreie Übertragung.
    *   Microkernel-Architektur mit hunderten von Plugins.
*   **Bedeutung:** Vorinstalliert in fast allen namhaften Linux-Distributionen (Debian, Ubuntu, Fedora, RHEL).

---

## Folie 4: Windows-Lösungen – WinSyslog & EventReporter
*   **WinSyslog:**
    *   Der erste Syslog-Server für Windows (seit 1996).
    *   Zentralisiert Syslog-Nachrichten von Routern, Switches und Linux-Servern nativ auf Windows-Systemen.
*   **EventReporter:**
    *   Spezialisiert auf das Monitoring und Weiterleiten von Windows Event Logs.
    *   Sehr schlanker Footprint; wandelt lokale Windows-Ereignisse in Syslog- oder RELP-Streams um.

---

## Folie 5: Enterprise-Lösungen – MonitorWare Agent & Rsyslog Windows Agent
*   **MonitorWare Agent:**
    *   Das "Schweizer Taschenmesser": Kombiniert die Funktionen von WinSyslog und EventReporter.
    *   Zusatzfunktionen: Datei-Monitoring, SNMP-Trap-Empfang, Port-Probing und Datenbank-Anbindung.
*   **Rsyslog Windows Agent:**
    *   Speziell entwickelt für die perfekte Integration von Windows-Umgebungen in rsyslog-Infrastrukturen.
    *   Bietet höchste Zuverlässigkeit durch native RELP-Unterstützung auf Windows.
    *   Fokus auf Performance und Enterprise-Features für große Serverfarmen.

## Folie 6: Das Adiscon Ökosystem – Wie die Produkte agieren
**Szenario: Hybrid-Infrastruktur (Windows & Linux)**
1.  **Erfassung:** Der **Rsyslog Windows Agent** oder **EventReporter** sammelt Logs auf Windows-Servern.
2.  **Sicherer Transport:** Über das **RELP-Protokoll** werden die Daten verschlüsselt und verlustfrei übertragen.
3.  **Zentralisierung:**
    *   Ein zentraler **rsyslog-Server** (Linux) nimmt die Daten entgegen, filtert und normalisiert sie.
    *   Alternativ agiert **WinSyslog** als zentraler Hub in reinen Windows-Umgebungen.
4.  **Verarbeitung:** Der **MonitorWare Agent** kann komplexe Regeln anwenden (z.B. Alarmierung bei kritischen Fehlern oder Speicherung in SQL-Datenbanken).
**Ergebnis:** Ein lückenloser, hochperformanter Datenfluss vom Endgerät bis ins Archiv.
